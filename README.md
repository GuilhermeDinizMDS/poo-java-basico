# ☕ POO Java Básico - Calculadora de IMC e Gestão de Dados

Projeto em Java desenvolvido para demonstrar a aplicação prática de conceitos fundamentais da **Programação Orientada a Objetos (POO)** e manipulação de entradas/saídas no terminal.

---

### 🚀 Funcionalidades

- **Cálculo de IMC:** Recebe o peso e altura do utilizador para calcular o Índice de Massa Corporal.
- **Classificação Automática:** Diagnostica a faixa de peso segundo as diretrizes da Organização Mundial da Saúde (OMS).
- **Abstração & Encapsulamento:** Estruturação dos dados através da classe `Pessoa` com atributos privados, métodos de cálculo e *getters*.
- **Tratamento de Entradas:** Configuração do `Locale.US` para aceitação correta de decimais no terminal via `Scanner`.

---

### 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java 17+
- **Editor/IDE:** VS Code (Visual Studio Code)
- **Ferramentas:** Extension Pack for Java, Git & GitHub
